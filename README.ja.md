# 月夜の庭園 · エマ

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

散歩をしたり、腰を下ろしたり、静かに一緒の時間を過ごせる、幻想的な月夜の邸宅。

青紫の空に淡い桜色の花が映え、邸宅の窓からは暖かな金色の光がこぼれます。花の小径をたどって水辺へ向かうことも、室内で休むことも、花の木の下に座って桜羽エマと景色を眺めることもできます。戦闘やクエストに急かされることはありません。静かな環境、自然な反応、誰かと同じ場所で過ごす生活感を大切にしています。

## ゲームの楽しみ方

- **一人称での散策**：庭園、テラス、二階建ての邸宅を歩き、さまざまな眺めを楽しめます。
- **幻想的な星空**：星々、星河、異世界の天体に、ゆっくり変化する雲と時折現れる流星が重なります。
- **エマの日常**：現在対応している範囲で散歩し、立ち止まり、景色を眺め、状況に応じてあなたの存在に反応します。
- **気軽なふれあい**：近づいたときの反応、頭をなでたときの笑顔など。プレイヤーは指定の座席で庭園を眺められます。
- **静かな音風景**：風や水の音と、間をあけて流れるBGM。音楽はオフにできます。
- **調整できる設定**：画面、音量、マウス、キー設定に加え、庭園のマップを用意しています。

## 基本操作

以下は初期設定のキーです。設定画面から変更できます。

| 入力 | 操作 |
|---|---|
| W / A / S / D | 移動 |
| マウス | 周囲を見る |
| Shift | 押している間、移動を速くする |
| E | 距離と状態が適切なときにエマとふれあう |
| F | 指定の座席で座る / 立つ |
| M | 庭園マップ |
| Esc | 設定 / 戻る |

ふれあいはゲーム内の案内に従ってください。エマが移動中、または別の行動をしている間は、一部の反応が一時的に使えなくなります。

## 現在のバージョンとダウンロード

現在はWindows向けの庭園体験版で、引き続き開発中です。エマの活動範囲は主に庭園と一階です。エマが自分で座ったり立ったりする行動は未完成で、アニメーションや場面の細部にも改善の余地があります。

**ゲームの一般向けダウンロードは、まだ公開していません。** 無料・非収益での公開を予定していますが、キャラクターモデルやその他の第三者素材を配布するための許諾確認が必要です。必要な許諾を得た後、本リポジトリのReleasesからゲームパッケージを公開する予定です。

本リポジトリには現在のコードと設定、今後のバージョン更新を保存しています。完全なシーン素材、キャラクターモデル、ゲームパッケージは含まれません。ソースコードをダウンロードするだけでは、ゲーム全体を実行できません。
