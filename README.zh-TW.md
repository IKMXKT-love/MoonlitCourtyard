# 月夜庭院 · 艾瑪

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

一座可以漫步、坐下、靜靜相伴的幻想月夜莊園。

藍紫色的天穹映著淡粉櫻花，暖金色的窗光從莊園中透出。你可以沿花徑走近水景，回到室內休息，也可以坐在花樹下，與櫻羽艾瑪一起看景。這裡沒有戰鬥和任務催促，重點是安靜的環境、自然的回應，以及有人陪伴的生活感。

## 遊戲體驗

- **第一人稱漫遊**：探索庭院、露臺與兩層莊園，尋找不同的觀景位置。
- **幻想星空**：繁星、星河與異世界天體，搭配緩慢變化的雲幕和偶發流星。
- **艾瑪的日常**：她會在目前支援的區域散步、停留、觀察風景，並依情境回應你的陪伴。
- **輕量互動**：靠近時回應、摸頭與微笑；玩家可以在指定座位坐下看景。
- **安靜的聲音**：風聲、水聲與間歇背景音樂，音樂可以關閉。
- **可調整體驗**：顯示、音量、滑鼠與按鍵設定，以及庭院地圖。

## 基本操作

以下為預設按鍵，可在設定中調整。

| 按鍵 | 功能 |
|---|---|
| W / A / S / D | 移動 |
| 滑鼠 | 觀察四周 |
| Shift | 按住加速 |
| E | 在適當的距離和狀態下與艾瑪互動 |
| F | 在指定座位坐下 / 起身 |
| M | 庭院地圖 |
| Esc | 設定 / 返回 |

互動以遊戲內提示為準。艾瑪正在移動或完成其他行為時，部分回應會暫時讓位。
