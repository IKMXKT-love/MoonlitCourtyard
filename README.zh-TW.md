## 怎樣遊玩

### 移動與姿態

| 按鍵 | 作用 |
|---|---|
| `W / A / S / D` | 移動 |
| `Mouse` | 觀察四周 |
| `Shift` | 按住加速 |
| `Space` | 跳躍 |
| `Ctrl` | 蹲下 / 起身 |
| `C` | 趴下 / 起身 |
| `X` | 仰躺 / 起身 |

### 艾瑪與場景

| 按鍵 | 作用 |
|---|---|
| `E` | 距離與狀態合適時，與艾瑪互動 |
| `F` | 在指定座位坐下 / 起身 |
| `G` | 摘花 / 展示 / 放下 |
| `R` | 靠近門時開關門 |

### 地圖與設定

| 按鍵 | 作用 |
|---|---|
| `M` | 查看庭院與樓層地圖 |
| `Esc` | 開啟設定 / 返回 |

上述為預設按鍵；可調整項目以遊戲設定為準。F需指定座位，R需靠近門，低姿態起身需足夠空間。

## 第一次進入庭院

1. 下載ZIP並完整解壓到資料夾。
2. 雙擊StartGarden.cmd或MoonlitCourtyard.exe，不需安裝UE編輯器。
3. 先使用預設中等畫質，再依電腦效能調整。
4. 沿花徑看景、靠近艾瑪體驗回應，再找個座位停留。

如缺少Microsoft Visual C++執行階段，Prerequisites提供微軟x64安裝程式。請保持Engine、MoonlitCourtyard資料夾與EXE在同一解壓位置。
