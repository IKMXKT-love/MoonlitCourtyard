## 플레이 방법

### 이동과 자세

| 입력 | 동작 |
|---|---|
| `W / A / S / D` | 이동 |
| `Mouse` | 주변 보기 |
| `Shift` | 누르는 동안 가속 |
| `Space` | 점프 |
| `Ctrl` | 웅크리기 / 일어서기 |
| `C` | 엎드리기 / 일어서기 |
| `X` | 반듯이 눕기 / 일어서기 |

### 에마와 환경

| 입력 | 동작 |
|---|---|
| `E` | 거리와 상태가 맞을 때 상호작용 |
| `F` | 지정 좌석에서 앉기 / 일어서기 |
| `G` | 꽃 꺾기 / 보여주기 / 놓기 |
| `R` | 가까운 문 열기 / 닫기 |

### 지도와 설정

| 입력 | 동작 |
|---|---|
| `M` | 정원과 층별 지도 |
| `Esc` | 설정 / 뒤로 |

기본 키입니다. 변경할 수 있는 항목은 게임 설정을 따릅니다. F는 지정 좌석, R은 문 근처에서 사용하고 낮은 자세에서 일어서려면 공간이 필요합니다.

## 처음 방문하기

1. ZIP 전체를 폴더에 압축 해제합니다.
2. StartGarden.cmd 또는 MoonlitCourtyard.exe 실행. Unreal Editor는 필요 없습니다.
3. 기본 중간 그래픽 설정부터 시작해PC성능에 맞게 조정합니다.
4. 꽃길을 걷고 에마에게 다가간 뒤, 좌석에서 잠시 머물러 보세요.

Visual C++런타임이 없으면Prerequisites의Microsoft x64설치 프로그램을 사용하세요. Engine과MoonlitCourtyard폴더를EXE곁에 유지하세요.

<details>
<summary>현재 체험판과 이후 방향</summary>

에마는 주로 정원과1층에서 활동합니다. 자율 계단 이동, 완전한 앉기·일어서기, 앉아서 독서, 꽃 직접 전달·착용은 활성화하지 않았습니다. 동작과 장면에 개선할 부분이 있고 간헐적인 입구 멈춤도 완전 해결은 확인되지 않았습니다.

</details>
