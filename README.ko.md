# 달빛 정원 · 에마

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

산책하고, 앉아서 쉬고, 조용히 함께 시간을 보낼 수 있는 환상적인 달밤의 저택.

푸른 보랏빛 하늘 아래 연분홍 벚꽃이 피고, 저택 창문에서는 따뜻한 금빛이 새어 나옵니다. 꽃길을 따라 물가로 걸어가거나, 실내로 돌아와 쉬거나, 꽃나무 아래 앉아 사쿠라바 에마와 함께 풍경을 감상할 수 있습니다. 전투나 퀘스트에 쫓길 필요는 없습니다. 고요한 환경, 자연스러운 반응, 누군가와 같은 공간에서 지내는 느낌에 집중한 경험입니다.

## 게임에서 즐길 수 있는 것

- **1인칭 탐험**: 정원, 테라스, 2층 저택을 거닐며 다양한 풍경을 발견할 수 있습니다.
- **환상적인 밤하늘**: 별과 은하, 이세계의 천체에 천천히 변하는 구름과 간헐적인 유성이 어우러집니다.
- **에마의 일상**: 현재 지원하는 구역에서 산책하고, 머무르고, 풍경을 바라보며 상황에 따라 플레이어의 존재에 반응합니다.
- **가벼운 상호작용**: 가까이 다가갔을 때의 반응, 머리를 쓰다듬었을 때의 미소 등을 즐길 수 있습니다. 플레이어는 지정된 좌석에 앉아 정원을 감상할 수 있습니다.
- **잔잔한 소리**: 바람과 물소리, 간헐적으로 흐르는 배경 음악. 음악은 끌 수 있습니다.
- **조절 가능한 설정**: 화면, 음량, 마우스, 키 설정과 정원 지도를 제공합니다.

## 기본 조작

아래는 기본 키이며, 설정에서 변경할 수 있습니다.

| 입력 | 기능 |
|---|---|
| W / A / S / D | 이동 |
| 마우스 | 주변 둘러보기 |
| Shift | 누르고 있는 동안 빠르게 이동 |
| E | 거리와 상태가 적절할 때 에마와 상호작용 |
| F | 지정된 좌석에 앉기 / 일어서기 |
| M | 정원 지도 |
| Esc | 설정 / 뒤로 |

상호작용은 게임 내 안내를 따라 주세요. 에마가 이동 중이거나 다른 행동을 수행하는 동안에는 일부 반응을 잠시 사용할 수 없습니다.

ZIP 전체를 폴더에 압축 해제한 뒤 `StartGarden.cmd` 또는 `MoonlitCourtyard.exe`를 실행하세요. 실행 파일 하나만 꺼내 실행하지 마세요. Unreal Editor 설치는 필요 없습니다. 기본 중간 그래픽 설정부터 시작해 컴퓨터 성능에 맞게 조정하세요. 현재 게임 UI는 주로 중국어이며 저장소 소개는 다섯 가지 언어 표기로 제공됩니다.

최근 변경: 화단·연못·벽난로·스테인드글라스 방문, 플레이어가 앉아 있을 때 함께 하늘 보기, 손에 든 꽃 표시 개선, 욕실 통합, 가구 배치 정리와 미닫이문, 입구·어두운 벽·분수 탈출·벽 틈 수정. 추가 조작: **G** 꽃 꺾기/보여주기/놓기, **R** 문, **Space** 점프, **Ctrl** 웅크리기, **C** 엎드리기, **X** 반듯이 눕기.

개발 중인 체험판입니다. 에마는 주로 정원과 1층에서 활동합니다. 자율 계단 이동, 완전한 앉기·일어서기, 앉아서 독서 및 꽃을 직접 받아 착용하는 행동은 활성화하지 않았습니다. 동작과 장면에 개선할 부분이 있으며 입구에서 간헐적으로 멈추는 문제의 완전 해결도 확인하지 못했습니다.

저장소에는 게임 코드, 설정, 설명과 이후의 커밋 기록을 보관합니다. 플레이하려면 Releases 패키지를 다운로드하세요. 원본 모델, 장면 제작 원본, 개인 저장 파일과 제작 중 초안은 코드 저장소에 포함하지 않습니다.
