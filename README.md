## 怎样游玩

### 移动与姿态

| 按键 | 作用 |
|---|---|
| `W / A / S / D` | 移动 |
| `Mouse` | 观察四周 |
| `Shift` | 按住加速 |
| `Space` | 跳跃 |
| `Ctrl` | 蹲下 / 起身 |
| `C` | 趴下 / 起身 |
| `X` | 仰躺 / 起身 |

### 艾玛与场景

| 按键 | 作用 |
|---|---|
| `E` | 状态与距离合适时，与艾玛互动 |
| `F` | 在指定座位坐下 / 起身 |
| `G` | 摘花 / 展示 / 放下 |
| `R` | 靠近门时开关门 |

### 地图与设置

| 按键 | 作用 |
|---|---|
| `M` | 查看庭院与楼层地图 |
| `Esc` | 打开设置 / 返回 |

上述为默认按键；可调整项以游戏内设置为准。F需要指定座位，R需要靠近门，低姿态起身需要足够空间。

## 第一次进入庭院

1. 下载上方ZIP，并完整解压到一个文件夹。
2. 双击 StartGarden.cmd 或 MoonlitCourtyard.exe。无需安装UE编辑器。
3. 先使用默认中等画质，再按电脑性能调整显示和声音。
4. 沿花径看看景，靠近艾玛体验回应，再找一个座位停留。

若提示缺少Microsoft Visual C++运行库，包内Prerequisites目录提供微软x64运行库安装程序。请保持Engine、MoonlitCourtyard目录和EXE在同一解压位置。
