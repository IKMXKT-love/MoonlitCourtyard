# 月夜庭院 · 艾玛

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

一座可以漫步、坐下、静静相伴的幻想月夜庄园。

蓝紫色的天穹映着淡粉樱花，暖金色的窗光从庄园中透出。你可以沿花径走近水景，回到室内休息，也可以坐在花树下，与樱羽艾玛一起看景。这里没有战斗和任务催促，重点是安静的环境、自然的回应，以及有人陪伴的生活感。

## 游戏体验

- **第一人称漫游**：探索庭院、露台与两层庄园，寻找不同的观景位置。
- **幻想星空**：繁星、星河与异世界天体，配合缓慢变化的云幕和偶发流星。
- **艾玛的日常**：她会在当前支持的区域散步、停留、观察风景，并根据情境回应你的陪伴。
- **轻量互动**：靠近时回应、摸头与微笑；玩家可以在指定座位坐下看景。
- **安静的声音**：风声、水声与间歇背景音乐，音乐可以关闭。
- **可调整体验**：显示、音量、鼠标与按键设置，以及庭院地图。

## 基本操作

以下为默认按键，可在设置中调整。

| 按键 | 功能 |
|---|---|
| W / A / S / D | 移动 |
| 鼠标 | 观察四周 |
| Shift | 按住加速 |
| E | 在适合的距离和状态下与艾玛互动 |
| F | 在指定座位坐下 / 起身 |
| M | 庭院地图 |
| Esc | 设置 / 返回 |

互动以游戏内提示为准。艾玛正在移动或完成其他行为时，部分回应会暂时让位。
